# 基于阿里云OSS的个人相册

## 项目简介

这是一个基于阿里云OSS存储服务的个人相册前端项目，提供了美观、高效的照片管理和展示功能。项目采用现代化的前端技术栈，具有响应式设计，可在各种设备上良好展示。

## 项目特点

- **现代化UI设计**：采用Tailwind CSS构建，界面美观、交互流畅
- **响应式布局**：适配PC端、平板和移动设备
- **模块化架构**：代码结构清晰，易于维护和扩展
- **丰富的交互功能**：轮播图、标签云、照片预览等
- **相册加密支持**：保护隐私照片
- **基于阿里云OSS**：安全可靠的存储方案
- **搜索功能**：支持按标签和关键词搜索照片

## 项目结构

```
album_web/
├── assets/             # 静态资源
│   ├── css/            # 样式文件
│   ├── images/         # 图片资源
│   └── js/             # JavaScript文件
│       ├── modules/     # 模块化代码
│       ├── config.js    # 配置文件
│       └── script.js    # 主入口文件
├── error/              # 错误页面
├── album.html          # 相册详情页
├── index.html          # 首页
├── tags.html           # 标签页
└── README.md           # 项目说明文档
```

## 核心功能

### 1. 首页
- 轮播Banner展示
- 相册列表展示
- 年份筛选功能
- 管理后台入口

### 2. 相册详情页
- 照片网格展示
- 视频播放支持
- 标签筛选功能
- 照片预览模态框
- 拍摄参数展示

### 3. 标签页
- 标签云展示
- 关键词搜索
- 照片类型筛选
- 搜索结果展示

### 4. 管理功能
- 从接口获取管理后台地址
- 在新标签页打开管理后台

## 技术栈

- **前端框架**：原生JavaScript (ES6+)
- **CSS框架**：Tailwind CSS (CDN)
- **图标库**：Font Awesome (CDN)
- **视频播放**：Video.js (CDN)
- **HTTP请求**：Fetch API
- **模块化**：ES Modules

## 接口说明

项目通过以下接口与后端服务通信：

| 接口地址 | 方法 | 功能描述 |
|---------|------|----------|
| `/api/open/site/info` | GET | 获取站点信息、Banner和相册列表 |
| `/api/open/site/config` | GET | 获取站点配置信息 |
| `/api/open/tags` | GET | 获取标签列表 |
| `/api/open/search/media` | GET | 搜索媒体资源 |
| `/api/open/albums/detail` | GET | 获取相册详情 |

## 配置说明

项目配置文件位于 `assets/js/config.js`，主要配置项包括：

- **API_CONFIG**：API基础地址配置
- **SITE_CONFIG**：站点默认配置
- **UI_CONFIG**：UI交互配置（轮播图、搜索等）
- **CACHE_CONFIG**：缓存配置（相册密码等）
- **ERROR_PAGES**：错误页面配置

## 本地开发

1. **启动本地服务器**

   ```bash
   # 使用Python内置服务器
   python -m http.server 8000
   
   # 或使用Node.js的http-server
   npx http-server -p 8000
   ```

2. **访问项目**

   打开浏览器，访问 `http://localhost:8000`

## 部署说明

1. **构建项目**

   项目为纯静态文件，无需构建过程。

2. **部署到服务器**

   将 `album_web` 目录下的所有文件上传到Web服务器的根目录或子目录。

3. **配置后端服务**

   确保后端服务已部署，并在 `assets/js/config.js` 中配置正确的API基础地址。
