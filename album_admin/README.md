# 基于阿里云OSS的个人相册 管理平台前端

## 项目简介

这是一个基于阿里云OSS的个人相册管理平台的前端部分，提供了完整的相册管理功能，包括站点管理、相册管理、媒体管理、标签管理和轮播图管理等功能。

## 技术栈

- **前端框架**：原生JavaScript + ES6模块
- **样式**：CSS3
- **存储**：阿里云OSS
- **认证**：JWT Token
- **API**：RESTful API

## 快速开始

### 环境要求
- 现代浏览器（Chrome, Firefox, Safari, Edge）
- 后端API服务（需配置`API_BASE_URL`）
- 阿里云OSS服务

### 配置说明

1. 修改 `js/config.js` 文件中的配置：

```javascript
// API基础地址
export const API_BASE_URL = 'http://localhost:8888/api';

// OSS配置
export const OSS_CONFIG = {
  REGION: 'oss-cn-shanghai',
  // Bucket名称会从站点配置中获取
};
```

### 运行项目

1. 将项目部署到Web服务器
2. 访问 `index.html` 进行登录
3. 登录后进入管理后台
